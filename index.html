03 / Короткий довідник

Створення та доступ

a = [12, 7, 18, 5]\nprint(a[0]) # 12\nprint(len(a)) # 4\na.append(20) # додати в кінець

Індексація починається з нуля. Останній елемент має індекс len(a)-1.

Перебір і фільтрація

for x in a:\n print(x)\n\nresult = []\nfor x in a:\n if x > 10:\n result.append(x)

Перебір за значеннями зручний, коли потрібно читати елементи. Для зміни елементів зазвичай потрібні індекси.

Статистика

sum(a) # сума\nmin(a) # мінімум\nmax(a) # максимум\nlen(a) # кількість\nsorted(a) # новий відсортований список

Підрахунок за умовою

count = 0\nfor x in a:\n if x % 2 == 0:\n count += 1

Остача від ділення на 2 дорівнює нулю для парних чисел.
