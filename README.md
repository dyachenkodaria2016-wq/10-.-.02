# LIST//LAB — Практикум з Python для 10 класу

Інтерактивний навчальний матеріал на тему **«Обробка одномірних списків даних»**.

## Склад
- `index.html` — повний автономний навчальний застосунок.

## Запуск локально
1. Завантажте `index.html`.
2. Відкрийте файл у сучасному браузері (Chrome, Edge, Firefox).
3. Зареєструйте учня та виконуйте завдання.

## Публікація на GitHub Pages
1. Створіть новий GitHub-репозиторій.
2. Завантажте `index.html` у корінь репозиторію.
3. Відкрийте **Settings → Pages**.
4. У розділі Build and deployment виберіть **Deploy from a branch**.
5. Виберіть гілку `main` і папку `/ (root)`, натисніть Save.
6. Після публікації відкрийте адресу GitHub Pages.

## Можливості
- реєстрація учасника (ПІБ, клас, заклад освіти);
- короткий довідник з Python;
- 9 завдань трьох рівнів складності;
- інтерактивні тестові та кодові вправи;
- підказки до кожного завдання;
- окрема оцінка 0–12 за кожне завдання;
- підрахунок спроб, помилок, часу та виконаних завдань;
- завантаження звіту HTML і друк / збереження як PDF.

## Важливе уточнення щодо симулятора
Редактор коду має навчальну перевірку структури алгоритму та ключових конструкцій. Він не є повноцінним інтерпретатором Python і не виконує довільний код. У консолі показується очікуваний результат для відповідної задачі; остаточна перевірка здійснюється за наявністю потрібних алгоритмічних конструкцій.
